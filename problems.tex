\section{Общие сведения}

Сборник содержит задания для семинарских занятий 
по курсу <<Объектно-ориентированное программирование на Python>> 
(64 часа).

Курс предполагает повторение основ объектно-ориентированного программирования, 
освоение автоматического тестирования, овладение всеми основными паттернами 
объектно-ориентированного программирования и DDD, а также введение в паттерны 
асинхронного/параллельного программирования.

Возможна сдача другого кода (например, выполненного в ходе
проектной деятельности), если они полностью покрывают материал семинара.

Оценивание работ осуществляется на основе следующих принципов:

\begin{itemize}
    \item строгий учёт сроков сдачи (при просрочке учитываются официальные документы 
    от врача и отправление на мероприятия в интересах ВУЗа, а также пропуск по причине
    назначения пересдач строго на время пары; возможен учёт других индивидуальных
    ситуаций), просрочка понижает оценку на 25 (но не 
    ниже 50), базовая оценка -- 100;
    \item каждая работа защищается (задаются вопросы и проводится собеседование по коду 
    и общим принципам), если защита не успешна несколько раз, то 
    оценка может быть понижена;
    \item если в работе обнаружены недостатки, то студенту предоставляется возможность
    их исправить без понижения оценки;
    \item оценка за практическую часть это средняя оценка всех работ с учетом того, что 
    недосданные работы оцениваются пропорционально ниже оценки, которая была бы получена
    при условии сдачи;
    \item на пересдаче осуществляется сдача работ, оценка на пересдаче 
    за конкретную работу не может быть выше 50 за исключением случая, 
    когда имеются оправдательные документы согласно первому принципу.
\end{itemize}

Итоговое оценивание осуществляется независимо по теории и практике:

\begin{itemize}
\item по теории вычисляется средний балл для всех письменных опросов (пропущенные 
дополнительные вопросы по уважительной причине не учитываются; основные опросы 
учитываются всегда);
\item по практике учитывается средний балл за все обычные практические задания и он 
имеет вес 40\%, а также учитывается средний балл за все offline-практики (выполняемые
на листочке по мотивам основных практических заданий) -- этот балл имеет вес 60\%;
\item зачёт выставляется при достижении не менее 50 баллов по теории и не менее 50 баллов
по практике;
\item в случае необходимости выставления оценки в 5-балльной шкале шкала перевода 
следующая: от 84 баллов -- 5, от 68 баллов -- 4, от 50+ баллов -- 3; на экзамене 
учитывается накопленный результат за год.
\end{itemize}
